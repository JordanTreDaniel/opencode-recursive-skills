# Timezones

Common timezone labels for converting suggested slots to an invitee's local
time. Pick the IANA name, never an abbreviation like "CST" (ambiguous).

- `America/New_York`
- `America/Chicago`
- `America/Denver`
- `America/Los_Angeles`
- `Europe/London`

Always present a suggested slot in both the host and invitee timezones.
