# Priority rubric

How to pick tags that convey urgency when the user does not specify one.

- `p1` — blocks someone else's work right now.
- `p2` — due within the current week.
- `p3` — everything else with a due date.
- no priority tag — no due date; add one only if asked.

Priority is expressed through `tags`, not a separate field. Never guess a
due date just to justify a priority tag.
